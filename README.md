# ADSO-Calidad-Git-ParejaX

Repositorio colaborativo del taller SQA - Clase 6: Control de versiones como práctica de calidad del software.

## Módulo de Registro

- Registro de usuarios con validación de campos obligatorios
- Validación de correo electrónico y prevención de correos duplicados

## Módulo de Reportes

- Generación de reportes en memoria y exportación real a PDF
- Generación de gráficos de barras SVG a partir de listas de números
- Por defecto, los archivos `reporte.pdf` y `grafico.svg` se crean en el
  directorio desde el que se ejecuta el programa; las funciones permiten
  indicar otra ruta de salida.

## Calculadora

- Suma, resta, multiplicación y división
- Reintentos ante entradas u operaciones no válidas, sin llamadas recursivas
- Se inicia al ejecutar `calculadora_basica.py` y no al importarlo
